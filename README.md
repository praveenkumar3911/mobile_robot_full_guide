# Mobile Robot Implementation Guide

Step-by-Step Build Guide

1. Physical Assembly: Start by assembling the chassis, then attach the motors, mount the LIDAR, and finally secure the Raspberry Pi and Teensy.

2. 2. Connection and Wiring: Connect the motors to the driver, encoders to Teensy (pins 5,6 and 7,8), and power everything with a 12V battery and 5V converter.
  
   3. 3. Software Setup: Install ROS on your Raspberry Pi, create a workspace, and clone this repository to compile the package.
     
      4. 4. First Run: Launch the visualization using the command provided in the Quick Start section.
